# PV Sound System (Forge 1.20.1)

Addon ของ [Plasmo Voice](https://github.com/plasmoapp/plasmo-voice) ที่เพิ่มลำโพง ซับวูฟเฟอร์ มิกเซอร์ DJ สายลำโพง และไมโครโฟน
ดึงเพลงจาก YouTube / SoundCloud / ลิงก์ http ผ่าน [pv-addon-lavaplayer-lib](https://github.com/plasmoapp/pv-addon-lavaplayer-lib)

## ทำไมเสียงถึงแยกซ้าย/ขวาได้จริง

- ลำโพงแต่ละตัวคือ **mono static source** ของ Plasmo Voice ที่ตำแหน่งของบล็อก ตัว client (OpenAL) จะ pan และลดเสียงตามระยะเอง
  หันหัวไปทางไหน เสียงก็ย้ายไปทางนั้น
- มิกเซอร์ถอดรหัสเพลงเป็น PCM stereo 48kHz แล้วผ่าน DSP ก่อน จากนั้นแยกเป็นช่อง **LEFT / RIGHT / MONO / SUB**
  แล้ว encode เป็น opus แยกตามช่อง (โหมด AUDIO, 96 kbps) ส่งไปยังลำโพงที่ตั้งช่องนั้นไว้
- พอวางลำโพง L กับ R ห่างกัน จะได้ภาพเสียงสเตอริโอจริงในโลก เดินเข้าใกล้ลำโพงฝั่งซ้าย เสียงฝั่งซ้ายก็จะดังกว่า
- ลำโพงมีทิศทาง (cone 270° ปรับได้ใน config) ถ้าเดินไปอยู่หลังตู้ เสียงจะเบาลง ส่วนซับวูฟเฟอร์กระจายเสียงรอบทิศ เหมือนเบสของจริง
- จะไม่ใช้ source แบบ stereo เพราะ Plasmo Voice ปิด panning ของ stereo source ทำให้เสียงไม่มีตำแหน่ง

## ไอเทม

| ไอเทม | การใช้งาน |
|---|---|
| **ลำโพง** | คลิกขวามือเปล่า: สลับช่อง ซ้าย → ขวา → โมโน (ไฟ LED บนหน้าตู้เปลี่ยนสีตาม: ฟ้า/แดง/เขียว) · ย่อ+คลิกขวา: ดูข้อมูล |
| **ซับวูฟเฟอร์** | ได้ช่อง SUB เสมอ (low-pass 110Hz) ปรับระดับด้วยปุ่ม Sub ระยะเสียงไกลกว่าลำโพงปกติ |
| **มิกเซอร์ DJ** | คลิกขวาเพื่อเปิดหน้าคอนโซล · comparator อ่านค่าความดัง 0–15 ได้ (เอาไปทำไฟเต้นตามเพลงได้) · มีไฟเมื่อกำลังเล่น |
| **สายลำโพง** | คลิกขวามิกเซอร์ = เสียบสาย → (คลิกขวาตัวยึดสายระหว่างทาง) → คลิกขวาลำโพง · ยาวเริ่มต้น 24 บล็อก วัดตามเส้นทางจริง |
| **ตัวยึดสาย** | ติดพื้น/ผนัง/เพดานได้ เหมือนปุ่ม ใช้จัดสายให้เดินเลาะผนังหรือเพดาน (คราฟ: เศษเหล็ก 5 → 8 ชิ้น) |
| **สายพ่วง** | ถือสายลำโพงไว้อีกมือ แล้วคลิกขวา = สายยาวขึ้น +16 บล็อก (สูงสุด 8 เส้น ปรับได้) |
| **ไมโครโฟน** | คลิกขวามิกเซอร์ = จับคู่ · คลิกขวากลางอากาศ = เปิด/ปิด · ถือไว้ในมือขณะเปิดอยู่ เสียงพูดจะออกลำโพงทุกตัวของมิกเซอร์นั้น |

### ลูกเล่นของการต่อสาย

- ถือสายที่เสียบมิกเซอร์ไว้ จะเห็นเส้น particle จากมิกเซอร์มาที่มือ ถ้าสายไม่พอ เส้นจะเป็น**สีแดง**
- ต่อสำเร็จจะมีประกายไฟวิ่งตามสาย และสายจะห้อยโค้งจริงจากหลังลำโพงไปยังมิกเซอร์ (มีแถบสีบอกช่อง L/R/M)
- **ย่อ + คลิกขวามิกเซอร์** = ต่อสายอัตโนมัติกับลำโพงทุกตัวที่ยังว่างอยู่ในรัศมี และตั้ง L/R ให้ตามทิศที่**คุณยืนมอง**
  ให้ยืนตรงจุดที่คนฟังจะยืน หันไปทางเวที แล้วกด ระบบจะตั้งลำโพงฝั่งซ้ายเป็น LEFT ฝั่งขวาเป็น RIGHT และตัวที่อยู่ตรงกลางเป็น MONO
- **จัดสาย:** หลังเสียบมิกเซอร์ ให้คลิกขวาตัวยึดสายตามลำดับทางเดินสาย แล้วค่อยคลิกขวาลำโพง สายจะห้อยผ่านตัวยึดทุกตัว
  ความยาวคิดตามเส้นทางจริง ย่อ + คลิกขวาตัวยึด = เอาออกจากเส้นทาง · ลำโพงที่ต่ออยู่แล้วคลิกซ้ำ = เดินสายใหม่
- ย่อ + คลิกขวาลำโพง = ถอดสาย · ย่อ + คลิกขวากลางอากาศ = ล้างเส้นทาง (กดอีกครั้ง = ม้วนสายเก็บ)

### ไมโครโฟน

ถือไมค์ที่เปิดอยู่ → แถบ action bar บอกสถานะ: `🎤 เปิดไมค์อยู่` (พร้อม) / `🎤 กำลังออกลำโพง` (เสียงเข้ามิกเซอร์จริง) / `มิกเซอร์ไม่ได้โหลด`
ปรับความดังด้วยปุ่ม **Mic** บนมิกเซอร์ ใส่ Echo เพิ่มได้

### /pvsound setting

หน้าตั้งค่าแบบ GUI (OP หรือเจ้าของโลก singleplayer):
- **yt-cipher**: ใส่ URL เอง หรือกดปุ่ม อัตโนมัติ / เครื่องนี้ / สาธารณะ / ในตัว · ปุ่ม **ทดสอบ** เช็คว่าต่อได้และรหัสถูกไหม
- **ค้นหา**: YouTube / YT Music / SoundCloud · ช่องทดสอบเพลง (ผลขึ้นในแชท)
- **สาย**: ความยาวเริ่มต้น, ความยาวต่อสายพ่วง, จำนวนพ่วงสูงสุด, ลำโพงต่อมิกเซอร์
- **ลำโพง**: ระยะลำโพง/ซับ, มุมลำโพง, bitrate
- กดบันทึกแล้วมีผลทันที (ระยะลำโพงเดิมอัปเดตเอง, เปลี่ยน cipher แล้วโหลด YouTube ใหม่ให้) และเขียนลง `config/pvsound-common.toml`

### หน้าจอมิกเซอร์

- ช่องใส่ลิงก์: วางลิงก์ YouTube, playlist หรือพิมพ์ชื่อเพลงเพื่อค้นหา (`ytsearch:`) ได้
  กด **Enter** = เล่นทันที · **Shift+Enter** = ต่อคิว
- ⏸ ⏭ ⏹ · Loop (ปิด / เพลงเดียว / ทั้งคิว) · ล้างคิว
- ปุ่มปรับ 10 ตัว (คลิกขวาที่ปุ่มเพื่อรีเซ็ต):
  - **Vol** ระดับเสียงรวม · **Bass/Mid/Treb** EQ ±12dB (120Hz / 1kHz / 6kHz)
  - **Bal** ปรับบาลานซ์ซ้าย/ขวา · **Width** ความกว้างสเตอริโอ (0% = โมโน, 200% = กว้างพิเศษ)
  - **Filt** ฟิลเตอร์ DJ: หมุนไปซ้ายเป็น low-pass sweep หมุนไปขวาเป็น high-pass sweep เหมาะกับช่วง build-up
  - **Echo** ดีเลย์แบบ ping-pong ที่เด้งเสียงสลับลำโพง L↔R · **Sub** ระดับซับ · **Mic** ระดับไมค์
- VU meter L / R / SUB พร้อม peak hold, แถบเวลาเพลง (สตรีมสดจะแสดง ● LIVE) และจำนวนลำโพงในแต่ละช่อง

ทุกช่องผ่าน limiter เสมอ ดันเสียงเท่าไหร่ก็ไม่แตก

## ติดตั้ง

### เซิร์ฟเวอร์ (Forge 1.20.1)
ใส่ในโฟลเดอร์ `mods/`:
1. `plasmovoice-forge-1.20.1-2.1.17.jar` (มีให้ใน `libs/`)
2. `pv-addon-lavaplayer-lib-1.2.3.jar` (มีให้ใน `libs/`)
3. `build/libs/pvsound-forge-1.20.1-1.0.0.jar`

### Client
ใส่ Plasmo Voice กับ `pvsound` (ต้องใช้ เพราะมีบล็อก/ไอเทม/GUI) ส่วน lavaplayer-lib ไม่ต้องใส่ เว้นแต่จะเล่นแบบ singleplayer

### Build
```
./gradlew build        # -> build/libs/pvsound-forge-1.20.1-1.0.0.jar
./gradlew runClient    # dev client
./gradlew runServer    # dev server (run-server/)
node tools/gen-textures.js   # สร้าง texture ใหม่
```

## Forward port

Plasmo Voice ส่งเสียงทาง **UDP** โดยค่าเริ่มต้นจะใช้พอร์ตเดียวกับ Minecraft ต้อง forward ทั้งสองแบบ:

| พอร์ต | โปรโตคอล | ใช้ทำอะไร |
|---|---|---|
| 25565 | TCP | Minecraft |
| 25565 | **UDP** | Plasmo Voice (เสียงพูด, เพลง, ลำโพง) |

- ถ้าเปลี่ยนพอร์ตเสียงใน `config/plasmovoice/server.toml` (`[host] port = ...`) ให้ forward UDP พอร์ตนั้นแทน
- ถ้า forward ผ่าน NAT/โดเมน แล้ว client ต่อเสียงไม่ได้ ให้ตั้ง `[host.public] ip/port` ใน server.toml เป็น IP สาธารณะ
- Windows Firewall: เปิด inbound ให้ `java.exe` ทั้ง TCP และ UDP
- **ไม่ต้อง** forward พอร์ต 8001 ของ yt-cipher เพราะมันผูกไว้ที่ 127.0.0.1 ใช้แค่ภายในเครื่อง

## Backend ของ YouTube (yt-cipher)

LavaPlayer รันอยู่ในเซิร์ฟเวอร์ Minecraft อยู่แล้ว ไม่ต้องมี Lavalink แยก
แต่ช่วงหลัง YouTube เปลี่ยน player script บ่อย client หลายตัวเลยต้องใช้ **remote cipher** ในการถอดรหัส signature
ใน `backend/` เตรียม [yt-cipher](https://github.com/kikkia/yt-cipher) ไว้ให้แล้ว:

```powershell
# เปิด Docker Desktop ก่อน
cd backend
.\start.ps1      # docker compose up -d -> http://127.0.0.1:8001/
```

มอดจะตรวจหา yt-cipher ที่ `http://127.0.0.1:8001/` เองตอนเปิดเซิร์ฟเวอร์/โลก (ค่า `remoteCipherUrl = ""` = auto)
ไม่ต้องแก้ config ถ้า backend รันบนเครื่องเดียวกัน ถ้ารันที่เครื่องอื่นให้ใส่ url เอง และตั้ง `remoteCipherPassword` ถ้าเปิด `YT_CIPHER_TOKEN`
ดู log ว่าขึ้น `YouTube remote cipher: http://127.0.0.1:8001/` — ถ้าขึ้น warning `remote cipher is not configured` แปลว่าตอนเปิดเกม backend ยังไม่รัน

ทดสอบได้ด้วยคำสั่ง `/pvsound test <ลิงก์หรือชื่อเพลง>` (ต้องเป็น op) จะบอกว่าหาเจอและถอดเสียงได้จริงไหม

ถ้ายังโหลด YouTube ไม่ได้ (เช่น ขึ้น "Sign in to confirm you're not a bot"):
- ตั้ง `useOauth2 = true` แล้วรีสตาร์ท ครั้งแรกที่เล่นเพลง log จะแสดงโค้ดให้ไปกรอกที่ google.com/device
  **แนะนำให้ใช้บัญชี Google สำรอง** หลังล็อกอินสำเร็จ refresh token จะถูกเก็บไว้ที่ `config/pvsound/.youtube-token`
- หรือใส่ `poToken` / `poVisitorData`
- หรือตั้ง `httpProxy` ถ้า IP ของเซิร์ฟเวอร์โดนบล็อก

## Config (`config/pvsound-common.toml`)

| ค่า | ค่าเริ่มต้น | |
|---|---|---|
| `youtube.clients` | MUSIC, ANDROID_VR, WEB, WEBEMBEDDED, TV, TVHTML5_SIMPLY | ลำดับ client ที่จะลองใช้ |
| `youtube.searchPrefix` | `ytsearch:` | ใช้ `ytmsearch:` เพื่อค้นใน YouTube Music หรือ `scsearch:` เพื่อค้นใน SoundCloud |
| `audio.opusBitrate` | 96000 | bitrate ต่อช่อง |
| `audio.speakerRange` / `subwooferRange` | 32 / 48 | ระยะได้ยินเป็นบล็อก |
| `audio.speakerConeAngle` | 270 | 0 = ลำโพงกระจายเสียงรอบทิศ |
| `gameplay.cableMaxLength` | 24 | ความยาวสายสูงสุด |
| `gameplay.maxSpeakersPerMixer` | 16 | |

ผู้เล่นปรับเสียงของลำโพงทั้งหมดได้ที่เมนู Plasmo Voice → แถบ **Speakers**

## ข้อจำกัด

- คิวเพลงเก็บไว้ในหน่วยความจำเท่านั้น รีสตาร์ทเซิร์ฟเวอร์แล้วคิวจะหาย แต่ค่าปุ่มปรับกับการต่อสายจะยังอยู่
- ถ้า chunk ของมิกเซอร์ถูก unload เพลงจะหยุด
- เสียงไมค์ที่ออกลำโพงจะช้ากว่าเสียงพูดปกติเล็กน้อย (ประมาณ 40–100ms) ผู้ฟังที่ยืนใกล้ทั้งคนพูดและลำโพงจะได้ยินเสียงซ้อนกันนิดหน่อย
